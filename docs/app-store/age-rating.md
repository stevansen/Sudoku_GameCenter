# Altersfreigabe

Fragebogen unter *App Store Connect → App → Altersfreigabe*. Alle inhaltlichen
Fragen (Gewalt, Schreckmomente, Sexualität, Schimpfwörter, Drogen, Glücksspiel,
Horror) werden mit **„Keine"** beziehungsweise **„Nein"** beantwortet.

| Frage | Antwort |
|---|---|
| Cartoon- oder Fantasy-Gewalt | Keine |
| Realistische Gewalt | Keine |
| Sexuelle Inhalte oder Nacktheit | Keine |
| Obszönitäten oder derber Humor | Keine |
| Alkohol, Tabak, Drogen | Keine |
| Simuliertes Glücksspiel | **Nein** |
| Glücksspiel mit echtem Geld | **Nein** |
| Schreckmomente / Horror | Keine |
| Uneingeschränkter Webzugriff | **Nein** |
| Nutzergenerierte Inhalte | **Nein** |
| Kontaktmöglichkeiten zwischen Nutzern | **Nein** |
| Standortweitergabe an andere Nutzer | **Nein** |

**Ergebnis: 4+.**

Bestenlisten und Erfolge über Game Center ändern die Freigabe nicht. Sie sind
**kein** simuliertes Glücksspiel — dort geht es um Zufallsmechaniken mit
Einsatzcharakter, nicht um Ranglisten.

Kategorie „Kinder" wird **nicht** gewählt: Sie zieht zusätzliche Auflagen nach
sich (unter anderem Einschränkungen bei Drittanbieter-Analytik und
Elternschranken) und die App richtet sich an alle Altersgruppen.
